

# Number Guessing Game

This is a simple number guessing game implemented in Java, where players try to guess a randomly chosen number within a specified range and a limited number of attempts.

## 🚀 Features

- **Random Number Generation**: The game randomly selects a number between 1 and 100.
- **Player Input**: Players can make guesses and receive hints.
- **Limited Attempts**: Players have a maximum of 5 attempts to guess the number.
- **Feedback Mechanism**: After each guess, players receive feedback indicating whether the guessed number is higher or lower than the target number.

## 🛠️ Tech Stack

- **Language**: Java
- **IDE**: Any Java-compatible development environment (e.g., Eclipse, IntelliJ IDEA)
